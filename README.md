# Мультиплеер: зачем разработчику сообщество

Лекция для Школы 21 о том, зачем разработчику IT-сообщества: видимость, слабые связи, с чего начать.
Автор — Роман Троицкий.

Слайды сделаны на [Slidev](https://sli.dev) без внешней темы: свои layout'ы лежат в `layouts/`,
компоненты в `components/`, стили в `style.css` и `styles/`. Шрифты подключены пакетами `@fontsource`,
поэтому колода собирается без сети.

## Что где лежит

- `slides.md` — точка входа: настройки колоды и титульный слайд.
- `pages/*.md` — акты доклада, подключаются из `slides.md` через `src:`.

## Запуск

Нужны Node.js 20+ и pnpm.

```bash
pnpm install
pnpm dev       # локальный сервер с автообновлением
pnpm build     # статическая сборка в dist/
pnpm export    # экспорт в PDF (нужен playwright-chromium)
```

На Windows `localhost` может резолвиться в IPv6 и браузер не достучится до сервера. Тогда запускай
`pnpm dev --remote` или открывай адрес, который напечатал Slidev.
